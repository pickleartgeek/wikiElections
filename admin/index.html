How this works on GitHub Pages: there's no server, so everything you change here saves to your browser's local storage and updates the live pages immediately for you. To make a change visible to everyone, use Export updated JSON below and commit the downloaded file over data/tsrelects-results.json.

Articles

Write and publish articles with a full rich-text editor. Saved locally like everything else here — use Export articles.json and commit it over data/articles.json to make it visible to everyone. Unpublished drafts save fine but won't show up on articles.html until you flip them to Published.

Moderator & Track-Record Approval — Add a Poll

Feeds the donuts on the homepage's off-cycle hub and the full trend on approval.html. Covers both moderator job-approval and the generic Community Track Record questions — same engine either way.
